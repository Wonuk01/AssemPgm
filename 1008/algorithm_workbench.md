# Chapter 5 --- Algorithm Workbench

> 원문의 Algorithm Workbench 1\~5를 한국어로 번역하고 풀이를
> 정리했습니다. 32비트 코드 기준입니다.

## 1

**질문:** `PUSH`와 `POP` 명령어만 사용하여 EAX와 EBX의 값을 서로
교환하는 명령어를 작성하라.

**답:**

``` asm
push eax
push ebx
pop eax
pop ebx
```

실행 전 `EAX=A`, `EBX=B`라면 실행 후 `EAX=B`, `EBX=A`가 된다.

## 2

**질문:** 서브루틴이 현재 스택에 저장된 반환 주소보다 메모리상 3바이트
높은 주소로 반환하도록 만들고 싶다. `RET` 직전에 넣을 명령어를 작성하라.

**답:**

``` asm
pop eax
add eax, 3
push eax
ret
```

반환 주소를 꺼내 3을 더한 뒤 다시 스택에 저장하면 `RET`이 수정된 주소로
이동한다.

## 3

**질문:** 고급 언어의 함수는 종종 반환 주소 아래쪽 스택 공간에 지역
변수를 만든다. 어셈블리 서브루틴 시작 부분에서 DWORD 정수 지역 변수
2개를 위한 공간을 예약하고, 각각 `1000h`, `2000h`를 저장하라.

**답:**

``` asm
sub esp, 8
mov DWORD PTR [esp],   1000h
mov DWORD PTR [esp+4], 2000h
```

프로시저 종료 전에 지역 변수 공간을 해제해야 한다.

``` asm
add esp, 8
ret
```

## 4

**질문:** 인덱스 주소지정을 사용하여 DWORD 배열의 한 요소를 같은 배열의
바로 이전 위치로 복사하는 명령어를 작성하라.

**답:** ESI가 복사할 원본 요소의 인덱스(바이트 오프셋)를 가리킨다고
가정하면 다음과 같이 작성할 수 있다.

``` asm
mov eax, array[esi]
mov array[esi-4], eax
```

DWORD 한 요소는 4바이트이므로 이전 요소의 위치는 현재 위치보다 4바이트
앞이다.

## 5

**질문:** 서브루틴의 반환 주소를 화면에 표시하는 명령어를 작성하라.
스택을 변경하더라도 서브루틴이 정상적으로 호출자에게 돌아갈 수 있어야
한다.

**답:** Irvine32의 `WriteHex`를 사용하는 예시는 다음과 같다.

``` asm
pop eax        ; 반환 주소를 EAX로 꺼냄
push eax       ; RET를 위해 즉시 다시 저장
call WriteHex  ; EAX의 반환 주소를 16진수로 출력
ret
```

핵심은 반환 주소를 확인한 뒤 반드시 스택에 다시 넣어 `RET`이 정상적으로
사용할 수 있게 하는 것이다.
