> 주제: Structures and Macros (구조체와 매크로)

## 1. STRUCT 지시어의 목적은?

**정답:** `STRUCT`는 여러 개의 관련된 데이터 필드를 하나의 구조체 형식으로 정의한다. 구조체를 정의한 뒤에는 해당 형식으로 여러 구조체 변수를 선언할 수 있다.

**해설:** C언어의 `struct`와 비슷하다. 구조체 형식은 `STRUCT`로 시작하고 `ENDS`로 끝난다.

## 2. RentalInvoice 선언의 유효성 판단

주어진 구조체:

```asm
RentalInvoice STRUCT
    invoiceNum BYTE 5 DUP(' ')
    dailyPrice WORD ?
    daysRented WORD ?
RentalInvoice ENDS
```

| 항목 | 선언 | 유효 여부 | 설명 |
|---|---|---|---|
| a | `rentals RentalInvoice <>` | O | `rentals`라는 구조체 변수를 선언한다. 모든 필드는 기본 초기화 상태로 둔다. |
| b | `RentalInvoice rentals <>` | X | MASM의 구조체 변수 선언 순서는 `변수명 구조체형식 초기값`이다. |
| c | `march RentalInvoice <'12345',10,0>` | O | 문자열 5바이트와 WORD 필드 2개를 순서대로 초기화한다. |
| d | `RentalInvoice <,10,0>` | X | 변수 이름이 빠져 있다. |
| e | `current RentalInvoice <,15,0,0>` | X | 구조체 필드는 3개인데 초기값 항목이 4개이다. |

## 3. 매크로에는 데이터 정의가 포함될 수 없다. (True/False)

**정답: False**

**해설:** 매크로 내부에는 데이터 정의문을 포함할 수 있다. 다만 매크로가 호출될 때마다 해당 코드가 확장되므로, 같은 이름의 데이터를 반복 정의하지 않도록 주의해야 한다.

## 4. LOCAL 지시어의 목적은?

**정답:** 매크로 내부에서 사용할 지역 레이블을 선언한다.

**해설:** 매크로가 여러 번 호출되면 일반 레이블 이름이 중복될 수 있다. `LOCAL`을 사용하면 매크로가 확장될 때마다 고유한 레이블 이름이 생성되어 이름 충돌을 방지한다.

## 5. 어셈블리 단계에서 콘솔에 메시지를 출력하는 지시어는?

**정답:** `ECHO` 또는 MASM의 `%OUT`을 사용할 수 있다. 교재에서 사용하는 지시어 표기에 맞춰 답하면 `%OUT`이다.

**해설:** 실행 중이 아니라 어셈블리 과정에서 메시지를 출력한다.

## 6. 조건부 블록의 끝을 표시하는 지시어는?

**정답:** `ENDIF`

**해설:** `IF`로 시작한 조건부 어셈블리 블록을 종료한다. `ELSE`는 선택적인 대체 구문이다.

## 7. 상수 Boolean 표현식에서 사용할 수 있는 관계 연산자를 모두 나열하시오.

**정답:**

- `EQ` : 같음
- `NE` : 같지 않음
- `LT` : 작음
- `LE` : 작거나 같음
- `GT` : 큼
- `GE` : 크거나 같음

## 8. 매크로 정의에서 & 연산자의 목적은?

**정답:** 매크로 매개변수와 주변 텍스트를 연결하여 하나의 텍스트로 만든다.

**해설:** 매개변수가 문자열이나 식별자 일부에 붙어 있을 때 매크로 전처리기가 매개변수의 끝을 구분하도록 `&`를 사용한다.

## 9. 매크로 정의에서 ! 연산자의 목적은?

**정답:** 바로 뒤에 오는 문자를 리터럴 문자로 취급하도록 한다.

**해설:** 매크로 인수 구분 등에 특별한 의미가 있는 문자를 일반 문자로 전달할 때 사용할 수 있다.

## 10. 매크로 정의에서 % 연산자의 목적은?

**정답:** 매크로 인수에 있는 텍스트 표현식을 어셈블러가 계산한 값으로 치환한다.

**해설:** 숫자 계산 결과를 매크로 확장 결과에 포함할 때 사용한다. 예를 들어 `% (2 + 3)`은 계산된 값 `5`로 치환되는 형태이다.

## 핵심 정리

| 지시어 / 연산자 | 핵심 역할 |
|---|---|
| `STRUCT ... ENDS` | 구조체 형식 정의 |
| `LOCAL` | 매크로 내부 지역 레이블 선언 |
| `IF / ELSE / ENDIF` | 조건부 어셈블 |
| `EQ, NE, LT, LE, GT, GE` | 관계 연산자 |
| `&` | 매크로 매개변수와 텍스트 연결 |
| `!` | 특수 문자를 리터럴로 취급 |
| `%` | 매크로 인수 표현식 계산 |
| `%OUT` | 어셈블리 단계 메시지 출력 |
