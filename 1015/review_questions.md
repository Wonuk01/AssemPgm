# Chapter 6 Conditional Processing --- Review Questions

## 1. AND 연산 후 BX 값

**질문:** 다음 명령어 실행 후 BX의 값은 무엇인가?

``` asm
mov bx,0FFFFh
and bx,6Bh
```

**답:** `006Bh`

**풀이:** `FFFFh`는 16비트가 모두 1이므로 어떤 값과 AND해도 상대 값이
그대로 남는다.

------------------------------------------------------------------------

## 2. AND 연산 후 BX 값

**질문:** 다음 명령어 실행 후 BX의 값은 무엇인가?

``` asm
mov bx,91BAh
and bx,92h
```

**답:** `0092h`

**풀이:** `91BAh AND 0092h = 0092h`.

## 6. XOR 연산 후 RBX 값

**질문:** 다음 명령어 실행 후 RBX의 값은 무엇인가?

``` asm
mov rbx,0AFAF649Bh
xor rbx,0FFFFFFFFh
```

**답:** 일반적인 x86-64의 `XOR r64, imm32` 해석에서는
`FFFFFFFF50509B64h`.

**풀이:** `0FFFFFFFFh` 즉시값은 64비트 XOR 명령에서 부호 확장되어
`FFFFFFFFFFFFFFFFh`로 적용되므로 전체 비트가 반전된다.

## 9. Carry, Zero, Sign 플래그 값

### a

``` asm
mov al,00001111b
test al,00000010b
```

**답:** `CF=0, ZF=0, SF=0`

**풀이:** TEST 결과는 `00000010b`로 0이 아니다. TEST는 CF를 0으로
만든다.

### b

``` asm
mov al,00000110b
cmp al,00000101b
```

**답:** `CF=0, ZF=0, SF=0`

**풀이:** 내부적으로 `6 - 5 = 1`.

### c

``` asm
mov al,00000101b
cmp al,00000111b
```

**답:** `CF=1, ZF=0, SF=1`

**풀이:** 내부적으로 `5 - 7 = -2`. unsigned 관점에서는 borrow가
발생하므로 CF=1이다.

------------------------------------------------------------------------

## 11. JA와 JNBE가 Zero/Carry 플래그의 영향을 받는 방식

**답:** 두 명령어는 같은 조건을 의미하며, `CF=0 AND ZF=0`일 때 점프한다.

-   `JA`: unsigned Above
-   `JNBE`: unsigned Not Below or Equal

------------------------------------------------------------------------

## 12. 최종 EDX 값

``` asm
mov edx,1
mov eax,7FFFh
cmp eax,8000h
jl L1
mov edx,0
L1:
```

**답:** `EDX = 1`

**풀이:** `JL`은 signed 비교이다. `7FFFh = 32767`, `8000h = 32768`이므로
32767 \< 32768이 참이라 점프한다.

------------------------------------------------------------------------

## 13. 최종 EDX 값

``` asm
mov edx,1
mov eax,7FFFh
cmp eax,8000h
jb L1
mov edx,0
L1:
```

**답:** `EDX = 1`

**풀이:** `JB`는 unsigned 비교이며 `7FFFh < 8000h`가 참이다.

------------------------------------------------------------------------

## 14. 최종 EDX 값

``` asm
mov edx,1
mov eax,7FFFh
cmp eax,0FFFF8000h
jl L2
mov edx,0
L2:
```

**답:** `EDX = 0`

**풀이:** signed 비교에서 `EAX=00007FFFh`는 32767이고 `FFFF8000h`는
-32768이다. 32767 \< -32768은 거짓이므로 점프하지 않고 `mov edx,0`이
실행된다.

------------------------------------------------------------------------

## 15. Target으로 점프하는가?

``` asm
mov eax,-30
cmp eax,-50
jg Target
```

**답:** **True**

**풀이:** signed 비교에서 -30 \> -50이므로 `JG`가 실행된다.

------------------------------------------------------------------------

## 16. Target으로 점프하는가?

``` asm
mov eax,-42
cmp eax,26
ja Target
```

**답:** **True**

**풀이:** `JA`는 unsigned 비교이다. -42의 32비트 표현 `FFFFFFD6h`는
unsigned로 매우 큰 양수이므로 26보다 크다.

------------------------------------------------------------------------
