# Average Calculator (32-bit MASM)

5개의 정수를 입력받아 합계와 평균을 계산하는 32비트 MASM 프로그램입니다.

## 실행 화면

![평균 계산 프로그램 콘솔 출력 재현](images/execution-result.png)

> **안내:** 위 이미지는 `AverageCalculator.asm`의 출력 형식을 바탕으로 제작한 **재현 화면**입니다. 실제 MASM/Irvine32 환경에서 컴파일·실행하여 캡처한 결과는 아닙니다.

### 화면에 표시된 출력 예시

```text
Enter integer #1: 10
Enter integer #2: 20
Enter integer #3: 30
Enter integer #4: 40
Enter integer #5: 53
Sum: +153
Average: 30.60
```

입력한 다섯 정수의 합계는 **153**, 평균은 **30.60**입니다.
